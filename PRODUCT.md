# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers, indie hackers, solo builders, and software engineers seeking validated project ideas and portfolio inspirations directly grounded in real-world user frustrations and community complaints.

## Product Purpose

Idea-man eliminates guesswork in software development by scanning authentic community discussions (target subreddits: r/SomebodyMakeThis, r/SideProject, r/webdev) and synthesizing raw rants into structured, ready-to-build software blueprints with target audiences, difficulty ratings, and recommended tech stacks.

## Positioning

Unlike generic AI prompt generators or brainstorm lists, Idea-man sources genuine qualitative pain points from active users begging for solutions, distilling them with Google Gemini into actionable blueprints with verified source attribution.

## Operating Context

- Web application built with Next.js App Router, Tailwind CSS, Supabase PostgreSQL, and Google Gemini API.
- Runs primarily in desktop and laptop developer environments as a discovery radar and project repository.

## Capabilities and Constraints

- Autonomous & on-demand Reddit mining via Gemini Flash extraction.
- Local repository bookmarks saved via browser local storage with real-time sync (Zero-Auth Personal MVP architecture).
- Search by keyword, problem, or technology stack with filterable categories and difficulty tiers.
- ElevenLabs-inspired warm cream editorial aesthetic (Bauhaus studio notebook: eggshell, warm-taupe, stone, ink, graphite, smoke).

## Brand Commitments

- Name: Idea-man
- Identity: Warm cream editorial with whispered headlines. Bauhaus studio notebook on cream paper. Restrained, authoritative, sober, and technically precise.
